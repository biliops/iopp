# iopp - 进程IO监控工具

iopp 是一个基于 Linux `/proc` 文件系统的进程文件IO监控工具，可以实时显示各进程的文件IO统计信息。

## 功能特性

- 实时监控进程的IO统计信息
- 支持多种显示格式（字节、KB、MB、自动单位）
- 支持隐藏空闲进程
- 支持显示完整命令行
- 可配置监控间隔和次数

## 支持的操作系统

**仅支持 Linux 系统**

该程序依赖 Linux 特有的 `/proc` 文件系统获取进程 文件IO 统计信息，其他系统（如 macOS、Windows）不支持。

## 安装方法

```bash
# 克隆仓库
git clone --depth 1 -b Make git@gitlab.com:higkoohk/hello.git ./iopp
cd ./iopp

# 编译安装（仅支持 Linux 操作系统）
make
sudo make install
```

## 使用方法

```bash
# 显示一次所有进程的IO信息
iopp

# 每秒刷新一次，持续监控
iopp 1

# 每2秒刷新一次，共显示5次
iopp 2 5

# 仅显示活跃进程
iopp -i

# 以人类可读格式显示（自动选择单位）
iopp -u

# 显示完整命令行
iopp -c
```

## 命令行选项

| 选项 | 长选项 | 说明 |
|------|--------|------|
| `-c` | `--command` | 显示完整命令行 |
| `-h` | `--help` | 显示帮助信息 |
| `-i` | `--idle` | 隐藏空闲进程 |
| `-k` | `--kilobytes` | 以千字节显示数据 |
| `-m` | `--megabytes` | 以兆字节显示数据 |
| `-u` | `--human-readable` | 自动选择合适的单位（B/K/M/G） |

## 输出字段说明

| 字段 | 说明 |
|------|------|
| 进程ID | 进程标识符 |
| 读字符 | 从文件读取的字符数 |
| 写字符 | 写入文件的字符数 |
| 系统读 | 系统调用读次数 |
| 系统写 | 系统调用写次数 |
| 读字节 | 实际磁盘读取字节数 |
| 写字节 | 实际磁盘写入字节数 |
| 取消写 | 被取消的写入字节数 |
| 命令行 | 完整的命令行信息 |

## 示例

```bash
# 每1秒刷新，显示活跃进程，使用人类可读格式
iopp -i -u 1

# 显示一次，以兆字节为单位
iopp -m

# 完整命令行模式
iopp -icu 10 31
```

## 卸载

```bash
sudo make uninstall
```
